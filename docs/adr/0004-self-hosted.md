# ADR 0004: Self-hosted na máquina do criador

- **Status:** Aceito
- **Data:** 2026-09-21

## Contexto

Os dados são sensíveis (saúde, emoções, TDAH) e o projeto é pessoal; serviços pagos de hospedagem adicionariam custo e exposição desnecessários.

## Decisão

Hospedar o app na própria máquina do criador, com os dados 100% locais.

## Consequências

Privacidade total e custo zero; disponibilidade depende da máquina estar ligada (aceitável para uso pessoal). Backup e cópia externa passam a ser responsabilidade explícita (ver ADR 0014).
